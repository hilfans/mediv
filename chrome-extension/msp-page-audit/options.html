API Key PageSpeed Insights (Google Lighthouse)

Dipakai khusus untuk fitur Cek Kecepatan (Lighthouse) — memanggil skor Performance/SEO/Accessibility/Best Practices asli dari Google, bukan sekadar heuristik internal ekstensi ini.

Penting soal keamanan: API key disimpan hanya di penyimpanan lokal browser Anda sendiri (chrome.storage.local), tidak pernah dikirim ke server PT MSP atau pihak lain selain langsung ke Google saat memanggil API. Tetap disarankan membatasi key ini di Google Cloud Console: aktifkan hanya PageSpeed Insights API, dan pertimbangkan batasan kuota harian supaya aman dari penyalahgunaan bila key ini bocor.
Setelah ekstensi ini di-publish ke Chrome Web Store: tambahkan juga Application restriction → HTTP referrers di Google Cloud Console dengan pola chrome-extension://ID_EKSTENSI_ANDA/*. Ini membuat key hanya bisa dipakai dari ekstensi ini sendiri, sekalipun bocor. Langkah lengkapnya ada di PUBLISHING.md pada folder sumber ekstensi ini.

Belum punya API key? Buat lewat Google Cloud Console → PageSpeed Insights API, lalu buat kredensial API key di halaman Credentials.
