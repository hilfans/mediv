API Key PageSpeed Insights (Google Lighthouse)

Dipakai khusus untuk fitur Cek Kecepatan (Lighthouse) — memanggil skor Performance/SEO/Accessibility/Best Practices asli dari Google, bukan sekadar heuristik internal ekstensi ini.

Penting soal keamanan: API key disimpan hanya di penyimpanan lokal browser Anda sendiri (chrome.storage.local), tidak pernah dikirim ke server PT MSP atau pihak lain selain langsung ke Google saat memanggil API. Tetap disarankan membatasi key ini di Google Cloud Console: aktifkan hanya PageSpeed Insights API, dan pertimbangkan batasan kuota harian supaya aman dari penyalahgunaan bila key ini bocor.
Setelah ekstensi ini di-publish ke Chrome Web Store: tambahkan juga Application restriction → HTTP referrers di Google Cloud Console dengan pola chrome-extension://ID_EKSTENSI_ANDA/*. Ini membuat key hanya bisa dipakai dari ekstensi ini sendiri, sekalipun bocor. Langkah lengkapnya ada di PUBLISHING.md pada folder sumber ekstensi ini.

Belum punya API key? Buat lewat Google Cloud Console → PageSpeed Insights API, lalu buat kredensial API key di halaman Credentials, atau ikuti tata cara lengkapnya di Cara Dapat API Key PageSpeed Insights →

API Key Gemini (Fitur Analisis AI, Opsional)

Dipakai untuk fitur bertanda "Analisis dengan AI" — mis. penilaian kualitas title/meta description dan ringkasan eksekutif laporan. Beda dari audit biasa, fitur ini mengirim cuplikan teks halaman (bukan cuma URL) ke Gemini API milik Google untuk dianalisis. Kalau Anda tidak mengisi key ini, semua fitur lain di ekstensi tetap berfungsi normal — bagian ini murni opsional.

Penting soal keamanan & privasi: API key dan data yang dikirim untuk dianalisis TIDAK PERNAH melewati server PT MSP — key disimpan hanya di chrome.storage.local perangkat ini, dan permintaan analisis dikirim langsung dari browser Anda ke Gemini API milik Google. Disarankan membatasi key ini di Google Cloud Console / Google AI Studio khusus untuk Generative Language API.
Setelah ekstensi ini di-publish ke Chrome Web Store: tambahkan juga Application restriction → HTTP referrers dengan pola chrome-extension://ID_EKSTENSI_ANDA/*, sama seperti key PageSpeed Insights di atas. Langkah lengkapnya ada di PUBLISHING.md.

Belum punya API key Gemini? Buat gratis lewat Google AI Studio → Get API Key. Tersedia tingkat gratis (free tier) dengan batas kuota harian dari Google.

API Key Bing Webmaster Tools (Cek Backlink, Opsional)

Dipakai untuk fitur Cek Backlink — melihat jumlah & daftar halaman yang menaut ke situs Anda, lewat Bing Webmaster Tools API. Kalau Anda tidak mengisi key ini, semua fitur lain di ekstensi tetap berfungsi normal — bagian ini murni opsional.

Beda penting dari dua API key di atas: Bing Webmaster Tools API HANYA mengembalikan data untuk situs yang sudah Anda tambahkan & verifikasi kepemilikannya di akun Bing Webmaster Tools yang API key-nya dipakai — tidak bisa dipakai untuk melihat backlink situs siapa pun secara bebas (beda dari Cek Kecepatan yang bisa untuk URL apa saja). Kalau domain yang Anda audit belum diverifikasi di akun itu, fitur ini akan menampilkan pesan error, bukan bug.
Penting soal keamanan: API key disimpan hanya di chrome.storage.local perangkat ini, tidak pernah dikirim ke server PT MSP. Berbeda dari API key Google, Bing Webmaster Tools tidak menyediakan pembatasan HTTP referrer seperti Google Cloud Console — kalau key ini bocor, satu-satunya cara memulihkannya adalah membuat key baru dari dashboard Bing Webmaster Tools dan menghapus yang lama.

Belum punya API key Bing Webmaster Tools? Tambahkan & verifikasi situs Anda dulu di Bing Webmaster Tools, lalu buat API key lewat menu Settings → API Access di dashboard-nya.
